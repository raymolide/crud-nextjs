# 🧑‍💻 Gestão de Utilizadores - Next.js + Prisma + NextAuth

Este é um projeto simples de **CRUD de Utilizadores** construído com **Next.js**, **Prisma** e **NextAuth**, com suporte a:

- Autenticação de utilizadores
- Definição de **roles** (admin, user, etc.)
- Páginas protegidas (acesso baseado em autenticação e permissão)
- Interface básica para criação, leitura, atualização e remoção de utilizadores

---

## 🚀 Tecnologias utilizadas

- [Next.js](https://nextjs.org/)
- [Prisma ORM](https://www.prisma.io/)
- [NextAuth.js](https://next-auth.js.org/)
- [SQLite](https://www.sqlite.org/) ou outro adaptador compatível com Prisma
- [Tailwind CSS](https://tailwindcss.com/) (opcional)

---

## ⚙️ Funcionalidades

- Registo e login de utilizadores com NextAuth
- CRUD completo de utilizadores
- Definição de **roles** (`admin`, `user`)
- Middleware de proteção de rotas baseado no role
- Painel administrativo (acesso restrito a admins)
- Estrutura escalável e pronta para produção
